Da página ao chat

Como o catálogo vira conversa

01

Coleta

Lê o HTML de cada página de coleção direto — sem navegador, sem Playwright — com retry automático em falha de rede.

02

Chave única

Cada item ganha uma chave página + id — várias coleções reusam ids genéricos, e isso colidia dados até ser corrigido.

03

Embeddings

Cada item vira um vetor de 768 dimensões, gerado via Gemini.

04

Índice

Os vetores entram numa coleção Qdrant única, com controle de mudança por hash.

05

Raciocínio

Um workflow N8N — hospedado localmente, não é infraestrutura de terceiros — busca o contexto, monta o prompt e chama o Gemini.

06

Conversa

Um widget embutível entra em qualquer página do site, sem exigir login.

Prévia funcional · busca híbrida, sem LLM

Sobre este protótipo

Ambiente de teste, não o site oficial

Esta página roda localmente, num ambiente privado, e usa nomes, descrições e fotos reais dos 707 itens do catálogo institucional da Harus — raspados do site público dela — pra demonstrar de forma honesta e completa o resultado do pipeline descrito acima. Não é operada, patrocinada ou endossada pela Harus, e não deve ser confundida com harus.ind.br, o site oficial da empresa. Nada aqui foi publicado publicamente (repositório privado, sem GitHub Pages) até confirmação explícita do autor.

Nenhuma etapa do scraping, da indexação ou do assistente depende de infraestrutura interna de nenhuma empresa terceira: o N8N é auto-hospedado via Docker (imagem oficial n8nio/n8n), o Qdrant e o Redis também, e a única chave externa necessária é uma API key pessoal do Google AI Studio — nada disso usa credencial, rede ou servidor de nenhum empregador.
