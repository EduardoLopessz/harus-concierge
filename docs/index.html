Projeto independente de portfólio — não é um produto oficial da Harus

Um concierge para um catálogo que não tinha busca.

O site institucional de uma indústria de amenities hoteleiras organiza 30 anos de linhas de produto em dezenas de páginas — mas nenhuma busca. Este projeto lê o catálogo inteiro, indexa cada item com embeddings e devolve uma interface de chat que responde por ele.

Ver a prévia Código no GitHub ↗
⚠️ Este site não é operado pela Harus — é um projeto autoral de Eduardo Elias Lopes, construído sobre o catálogo institucional público da empresa. Usa nomes, descrições e fotos reais dos 707 itens indexados (raspados do site oficial) só pra demonstrar o resultado do pipeline — repositório privado até confirmação de uso, não publicado publicamente.
Da página ao chat

Como o catálogo vira conversa

01

Coleta

Lê o HTML de cada página de coleção direto — sem navegador, sem Playwright.

02

Chave única

Cada item ganha uma chave página + id — várias coleções reusam ids genéricos, e isso colidia dados até ser corrigido.

03

Embeddings

Cada item vira um vetor de 768 dimensões, gerado via Gemini.

04

Índice

Os vetores entram numa coleção Qdrant única, com controle de mudança por hash.

05

Raciocínio

Um workflow N8N busca o contexto certo, monta o prompt e chama o Gemini.

06

Conversa

Um widget embutível entra em qualquer página do site, sem exigir login.
